# Cinta90

Convierte una foto o un vídeo en una cinta casera de los 90. Tú decides cuánto ruido, cuánta interferencia y qué fecha sale en pantalla.

[Abre Cinta90](https://1ly4s0.github.io/cinta90/)

El sitio usa HTML, CSS y JavaScript. Los archivos se procesan en el navegador. La vista previa se dibuja en Canvas. El vídeo se graba durante la reproducción con MediaRecorder y se guarda como MP4 o WebM según el navegador.

## Desarrollo local

Desde la carpeta del proyecto, sirve los archivos con `python -m http.server 8000` y abre `http://localhost:8000/`.

La portada en español está en `index.html` y la versión en inglés en `en/index.html`. GitHub Pages sirve ambos archivos desde la raíz de `main`.
